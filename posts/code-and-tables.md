## 코드 블록

코드 블록은 내용을 해석하지 않고 그대로 보여줍니다. 아래 코드는 일부러 한 줄을 아주 길게 썼습니다. 좁은 화면에서도 **페이지가 아니라 코드 블록 안에서만** 가로로 스크롤되어야 합니다.

```js
const posts = await fetch('posts/index.json').then((response) => response.json()); // 이 줄은 일부러 아주아주 길게 써서 모바일 화면 폭을 넘기도록 만든 예시입니다.

function greet(name) {
  return `안녕하세요, ${name}!`;
}
```

HTML처럼 보이는 글자도 코드 안에서는 그대로 보입니다.

```html
<button type="button" class="theme-toggle">**굵게 처리되지 않습니다**</button>
```

문장 안에서 `<script>alert(1)</script>` 같은 글자를 써도 실행되지 않고 글자로만 보입니다.

## 넓은 표

열이 많은 표도 표 영역 안에서만 스크롤됩니다.

| 이름 | 역할 | 입력 | 출력 | 의존성 | 비고 |
| --- | --- | --- | --- | --- | --- |
| `markdown.js` | 마크다운을 HTML로 변환 | 마크다운 문자열 | HTML 문자열 | 없음 | DOM을 모르는 순수 함수 |
| `frontmatter.js` | 글 맨 위 메타데이터 분리 | 파일 전체 문자열 | 메타데이터와 본문 | 없음 | 단순한 `key: value`만 지원 |
| `posts.js` | 글 불러오기 | slug | 글 객체 | `fetch` | 한 번 불러온 글은 캐시 |
| `render.js` | 화면 그리기 | 라우트 | DOM | 위의 모든 모듈 | DOM을 만지는 유일한 곳 |

## 중첩된 구조

1. 먼저 글을 씁니다
   - 제목을 정하고
   - 본문을 채웁니다
2. 그다음 확인합니다
   1. 라이트 모드
   2. 다크 모드
